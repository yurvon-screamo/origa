# Changelog

Источник поля «Что нового» в RuStore: джоба `upload-rustore`
(`.github/workflows/_upload-rustore.yml`) перед загрузкой AAB извлекает
секцию текущей версии из этого файла скриптом
`.github/scripts/extract-whatsnew.sh`.

## Формат

- Заголовок секции — `## X.Y.Z`: ровно номер тега без `v`, без даты. Новейшая секция сверху.
- Внутри секции — буллеты (дефис и пробел), по-русски; суммарно ≤500 символов **включая переводы строк** (лимит поля «Что нового» RuStore; скрипт считает символы и падает при превышении).
- Запрещены: ссылки, инлайн-код, вложенные заголовки, эмодзи — витрина RuStore это не переваривает.
- Секция версии должна быть заполнена **до пуша stable-тега**: отсутствующая или пустая секция роняет `upload-rustore` до создания черновика. Recovery при падении — ручной ресабмит через RuStore Console (см. AGENTS.md → Git).
