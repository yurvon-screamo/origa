# Google Trends для вьетнамского рынка (VI)

Инструмент → как получить данные → что смотреть → куда сохранить. Формат един для всех гайдов серии.
Контекст и предыдущие срезы: `docs/marketing/research/2026-09-16-keyword-research.md` (§15, §15.2).

## 1. Инструмент

Google Trends (geo=VN) — относительный интерес 0–100 по вьетнамскому Google. VI-рынок
практически целиком Google (доля Naver/Яндекс ≈ 0), поэтому Trends здесь — корректная
картина рынка, в отличие от KO, где Google покрывает лишь половину поиска.

- Обёртка: `pytrends` (неофициальный API).
- Ключей не требует; анонимный доступ, но есть rate-limit — между запросами пауза 3–10 сек,
  при бане кода 429 выждать минуту.
- **Критичный пин:** `urllib3<2` (с urllib3 2.x сырой API отдаёт 401). Зафиксировано в §15,
  воспроизводится.

Окружение (проверено 2026-10-12): `~/origa/marketing/vi/tools/venv` (uv venv, pytrends +
urllib3 1.26.20). Скрипт среза: `~/origa/marketing/vi/tools/slice_trends_vi.py`.

## 2. Как получить данные

```bash
cd ~/origa/marketing/vi/tools
uv venv venv && uv pip install --python venv/bin/python pytrends "urllib3<2"
./venv/bin/python slice_trends_vi.py   # выводит JSON: interest + related_queries
```

Параметры запроса: `TrendReq(hl='vi-VN', geo='VN')`.

Два режима `build_payload`, важно их не смешивать:

- **Батч (до 5 сидов)** — значения нормируются внутри батча и сравнимы между собой.
  Это режим для срезов «как в §15»: реплика батча даёт числа, сопоставимые с прошлым срезом.
- **По одному сиду** — каждый нормируется к собственному пику (=100), числа между сидами
  несравнимы. Пригоден для формы кривой (сезонность, последние 4 недели против среднего).

`related_queries(seed)` — top (0–100) и rising (% роста) вокруг сида. Отдельный вызов.

Для абсолютов (объёмы в месяц) Trends не пригоден — только Bing Webmaster
`GetKeywordStats` (§15.2–§15.3) или Keyword Planner вручную. Trends отвечает на
«что растёт и во что превращается сид», не на «сколько запросов».

⚠️ Статус абсолютов (2026-10-12): Bing `GetKeywordStats` деградировал — отдаёт
пустой `{"d":[]}` на всех рынках, включая работавший в сентябре us/en-US
(заявка `projects/origa/bing-getkeywordstats-degraded` в uwuwu). Перед любым
использованием — ретест; VI-абсолюты через Bing на паузе. Взамен «кто нас
ставит» по VI теперь снимается через общий GSC сервис-аккаунт (срез
`docs/marketing/research/2026-10-12-gsc-slice.md`, гео-разрез VI внутри).

## 3. Что смотреть

1. **Батч-реплика фиксированных сидов** — единственное, что сравнимо с историческими
   срезами. Сиды §15: `japanese`, `học tiếng nhật`, `hán tự`,
   `tiếng nhật cho người mới`, `app học tiếng nhật`. Держать состав батча неизменным.
2. **last 4 weeks против 12m-average** — сезонность. У VI он привязан к учебному году
   (сентябрь) и JLPT-окну (регистрация на декабрь — август–октябрь).
3. **related top** — во что превращается сид в голове аудитории: соседние сиды показывают
   интент (пути обучения против приложений).
4. **related rising** — свежий спрос. Обязательно чистить мусор: во VI rising забивается
   вопросами викторин-приложений (тесты «quốc kỳ của nước nào…» с % роста 13000+).
5. **Мусор-сид «japanese»** (английское слово) держать в батче только как якорь
   сопоставимости с §15; контентных решений по нему не принимать.
