## Статус доступов

Ключ есть (`marketing/.env`: `RUSTORE_KEY_ID` + `RUSTORE_PRIVATE_KEY_PATH` → `keys/rustore_private_key.b64`, id приложения 2351033386, пакет `net.uwuwu.origa`). Работает: рейтинг, отзывы, статусы версий, публикация (последняя уже в CI `upload-rustore`).

## Как получить данные

Схема авторизации (JWE, TTL 900 сек, потом заново):

1. `timestamp` = текущее время ISO-8601 с миллисекундами и TZ (допуск ±60 сек от серверного).
2. Подпись: `Base64(RSA-SHA512(keyId + timestamp))` приватным ключом (PKCS1v15).
3. `POST https://public-api.rustore.ru/public/auth` `{"keyId", "timestamp", "signature"}` → `body.jwe`.
4. Дальше каждый запрос с заголовком `Public-Token: <jwe>`.

Приватный ключ приходит из консоли как Base64 — декодировать перед `load_pem/der_private_key` (проверено: в b64 лежит DER/PKCS#8).

Готовый скрипт: `marketing/ru/tools/rustore_slice.py` (auth + рейтинг + отзывы одним прогоном).

## Что смотреть (метрики витрины)

| Метод | Что даёт |
| --- | --- |
| `GET /public/v1/application/{pkg}/comment/statistic` | средний рейтинг, разбивка 1–5, кол-во оценок, сколько без ответа |
| `GET /public/v1/application/{pkg}/feedback` | отзывы с текстом (body — список; пустой = оценок с текстом нет) |
| `GET .../feedback/csv` | выгрузка всех отзывов за период |
| `GET /public/v1/application/{pkg}/version` | статусы версий (сверка релизов с CHANGELOG) |

Замечание: статистики установок/просмотров в Public API нет — только в веб-Консоли руками (CSV). Полная витрина = этот API + ручной CSV раз в неделю.
