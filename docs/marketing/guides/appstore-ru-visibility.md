# App Store: RU-видимость и тренды (гайд)

> Формат: инструмент → как получить данные → что смотреть → куда сохранять.
> Дата валидации: 2026-10-12 (@origa_marketing_ru_bot). Скоуп: общий стек + RU-срез.
> Смысловой сдвиг против веб-трендов: в сторе «кто нас ставит» отвечает ASC Analytics (нужен ключ), а витринную видимость и конкурентов даёт публичный iTunes API без ключей.

## Картина доступов (2026-10-12)

| Инструмент | Статус | Что даёт |
| --- | --- | --- |
| iTunes Search API | ✅ автономно, без ключа | позиция приложения по термину, топ-конкуренты, рейтинг/кол-во оценок карточки, по country |
| iTunes RSS customerreviews | ✅ автономно | последние отзывы по app id и country |
| App Store Connect Analytics API | ❌ нужен ключ владельца | impressions/page views/downloads/conversion, источники установок, поисковые термины стора — «кто нас ставит» |
| App Store suggest-эндпоинт (MZStoreHints) | ☠️ мёртв (404, проверено 2026-10-12) | — |
| Веб-тренды (pytrends) | ✅ см. тренд-гайды | прокси спроса на темы, не на стор-запросы |

Рапорт владельцу (2026-10-12): нужен ключ App Store Connect API (App Store Connect → Users and Access → Integrations → Team Access Keys, роль с Analytics; .p8 + Key ID + Issuer ID) → `marketing/.env`. Без него «кто нас ставит в сторе» не измеряется ничем публичным.

## Инструмент 1: iTunes Search API (витринная видимость)

### Как получить данные

```
GET https://itunes.apple.com/search?term=<term>&country=ru&entity=software&limit=50
GET https://itunes.apple.com/lookup?id=<trackId>&country=ru
```

- Без ключа, лимит мягкий (~20 запросов/мин); пауза 1–1.5 с.
- `country` задаёт витрину (ru/us/jp — разные выдачи и разные рейтинги).
- Позиция своего приложения = индекс в `results`; поиск глубже 50 не прозрачен.

### Что смотреть

1. Позиция по целевым терминам (тренд-кандидаты из веб-гайдов = термины для стора).
2. Топ-1 конкурент по каждому термину — фактический конкурент за интент (не по маркетинговым спискам).
3. Карточка: `averageUserRating`/`userRatingCount` по рынкам — база конверсии; `currentVersionReleaseDate` — свежесть витрины.

### Срез 2026-10-12 (RU-витрина, 12 терминов, топ-50)

- **Origa не входит в топ-50 ни по одному из 12 RU-терминов** («японский язык», «изучение японского», «учить японский», «японский с нуля», «кандзи», «хирагана», «jlpt», «японский для начинающих», «японский офлайн», «лучшее приложение японский», «аниме японский», «японский переводчик»). Вне топ-50 и на us/jp («japanese», «learn japanese», «jlpt»).
- RU-карточка: rating 0, оценок 0; US: rating 0. Обновление витрины 2026-09-25. RSS-отзывы: 0 в RU и US.
- Топ-1 конкуренты по RU-терминам (захватывают интент прямо сейчас): «японский язык» → Японский язык хирагана/алфавит (PLANB LABS, 4.82/4599); «jlpt» → Migii JLPT (совпадает с позиционированием «использовать вместе»); «кандзи» → PORO; «хирагана» → MARU; «японский переводчик» → Yomiwa.
- Вывод: на текущей фазе узкое место стора — не ASO-ключи, а отсутствие социальных доказательств (0 оценок) и, вероятно, слабые стор-метаданные. Веб-тренды стора не видят; пока оценок нет, вкладываться в стор-термины рано, приоритет — получить первые оценки (запрос рейтинга в приложении — продуктовая рекомендация, паркую лиду) и меты карточки по подсказкам конкурентов.

## Инструмент 2: iTunes RSS customerreviews

```
GET https://itunes.apple.com/RU/rss/customerreviews/id=<appId>/sortby=mostrecent/json
```

Отзывы последними партиями, по странам. Пока count=0 — мониторить раз в неделю; первые отзывы = сырьё для FAQ/compare и ответов (ответ на отзыв в сторе руками владельца).

## Инструмент 3: ASC Analytics API (после выдачи ключа)

Единственный источник «кто нас ставит»: impressions по источникам (App Store Search / Explore / referral), поисковые термины стора, page view → download конверсия. Скрипт добавлю сюда же после ключа.

## Куда сохранять

- Гайды: `docs/marketing/guides/`; срез-JSON не коммитим, числа — сюда с датой.
- Ключи: `marketing/.env` (ASC_KEY_ID, ASC_ISSUER_ID, ASC_P8_PATH) — не в чат/репо.
- Находки: uwuwu-заявки (проект origa).

## Аддендум 2026-10-12: ASC-мета витрины (снято через ASC API)

JWT (ES256, kid+issuer из .env) работает: `GET /v1/apps/6795012532/appStoreVersions` + `appStoreVersionLocalizations`.

- **RU-локаль витрины: subtitle пуст**, keywords (12): японский, jlpt, кандзи, кана, иероглифы, карточки, словарь, аудирование, повторение, грамматика, манга, аниме.
- EN-локаль: subtitle тоже пуст; keywords 13 (kanji, kana, srs, flashcards, vocab, dictionary, ocr, anime, manga, furigana, nihongo, study, memorize).
- Вывод: subtitle (до 30 символов) не используется ни в одной локали — прямой ASC-пакет кандидат: RU-подзаголовок под «с нуля/JLPT»-интент из suggest-среза.

**Блокер**: Analytics Reports API (`/v1/analytics/reportRequests`, `reportInstances`) отдаёт 404 на оба пути при рабочем JWT — вероятная причина: роль ключа без «Access to Reports». Владельцу: пересоздать ключ ASC с ролью Admin или Access to Reports; после этого снять RU-territory показы/загрузки.
