- Google и **Naver делят корейский веб-поиск примерно пополам**; Naver — не «одна из площадок», а отдельная поисковая система со своим autocomplete, своими блогами (blog.naver.com) и комьюнити (cafe/DC Inside).

## 1. Google Trends через pytrends

**Как получить.** Системный pip отсутствует; рабочее окружение:

```bash
python3 -m venv /tmp/opencode/ko-trends-venv
/tmp/opencode/ko-trends-venv/bin/pip install "pytrends" "urllib3<2" requests
```

`urllib3<2` обязателен (§15). Запрос из датацентрового IP ловит 429 — помогает пауза 45–60 с и `TrendReq(..., retries=2, backoff_factor=2)`; параметр `hl='ko', geo='KR'`. `related_queries()` на гео-KR регулярно отдаёт HTTP 400 — связки related снимать повтором позже или брать из §15.2 (там снято).

**Что смотреть.** Среднее interest_over_time за 12 мес и за последние 3 мес; помесячная сезонность — для JLPT-кластера.

**Срез 2026-10-12 (geo=KR, среднее за 12 мес):**

| Запрос | 12 мес | последние 3 мес |
|---|---|---|
| jlpt | **38.4** | 35.6 |
| 일본어 공부 | 4.9 | 4.2 |
| 일본어 배우기 | 0.1 | 0.2 |
| 일본어 독학 / 한자 공부 | ниже порога | — |

JLPT-помесячно (0–100, сид «jlpt»): круглый год 25–49 без мёртвых месяцев; локальные пики ноя–янв (регистрация на декабрьский хвост + результаты) и июнь (июльская сессия). Ниша «일본어 능력시험» в Google ≈ 0 — аудитория набирает латиницу.

**Куда сохранять.** Выводы — в этот гайд или в `research/` с датой; сырые прогоны не хранить (429 делает их невоспроизводимыми байт-в-байт), хранить скрипт + таблицу агрегатов.

## 2. Naver Suggest — autocomplete без ключа (главный KO-инструмент)

**Как получить.** Открытый endpoint, без авторизации:

```
https://ac.search.naver.com/nx/ac?st=1&r_lt=1&q=<urlencoded seed>
```

Ответ: `{"query": [...], "items": [[["s1"], ["s2"], ...]]}` — подсказка = `items[0][i][0]`.
⚠️ Грабёж: `it[0][0]` даёт первый *символ* подсказки («일», «j»), а не подсказку. Правильно: `[it[0] for it in items[0]]`.
Задержка 0.4–0.5 с между запросами; алфавитное расширение — seed + хангыльные согласные 가나다라마바사아자차카타파하.

**Что смотреть.** Кросс-seed частоты (≥2 = сигнал), модификаторы, чужие бренды-магниты.

**Срез 2026-10-12 (топ-10 по сидам):**

| Сид | Подсказки (порядок Naver) |
|---|---|
| 일본어 공부 | 어플 · 공부법 · 책 · 순서 · 시바시바 일본어 공부 · 치이카와 일본어 공부 · 애니 · 무료 어플 · 책 추천 |
| jlpt | 시험일정 · 접수 · 등급 · n5 · n3 · n4 · n1 · 시험 |
| 일본어 어플 | 무료 · 추천 · 비교 · 순위 · 회화 · 내돈내산 |
| 일본어 독학 | 책 추천 · 첫걸음 · 방법 · pdf · 교재 · 기간 · 앱 |
| 한자 공부 | 성인 한자 공부 · 일본어 한자 공부법 · 공부방 · 책 · 앱 · 추천 |
| 일본어 | 교과서 · 책 · 사전 · 문장 · 기초 |

Наблюдения: (1) app-интент жив и пишется 어플 — наш кластер best-japanese-learning-app прямо ложится; (2) «공부법/순서/방법/기간» — метод-модификаторы = наши how-to-статьи; (3) бренды Chiikawa и 시바시바 — готовые магниты для контента (만화/애니-угол); (4) 무료/내돈내산 — free-угол обязателен в любых лендингах под KO.

**Куда сохранять.** Прогоны — в `research/` с префиксом даты; методика — уже в uwuwu (`keyword-research-stack`).

## 3. Naver Data Lab — официальный API трендов (✅ работает через партнёрскую пару)

**Статус:** работает с 2026-10-13. Пара ключей от партнёрского проекта (Developers Center legacy — ключи, выданные до закрытия 2026-07-31, работают до fade-out 2027-06-30). Значения — только в `marketing/.env` (`NAVER_DATALAB_CLIENT_ID` / `NAVER_DATALAB_CLIENT_SECRET`), в репо не хранятся; скрипт без env завершается ошибкой. Долгосрочно — миграция на собственный NCP-аккаунт (uwuwu `projects/origa/naver-datalab-access-2026`: developers-путь для новых заявок закрыт 31.07.2026; NCP global-узел ncloud.com/en — Individual-регистрация, японский узел требует JP-юрлицо).

**Как получить данные.** `POST https://openapi.naver.com/v1/datalab/search`, заголовки `X-Naver-Client-Id` / `X-Naver-Client-Secret`, body: `keywordGroups` (до 5 групп × 20 keywords), `timeUnit=month`, данные с 2016-01-01. Скрипт: `marketing/ko/scripts/datalab_slice.py` (маркетинг-репо).

**Что смотреть.** Сиды из §2, группы «일본어/jlpt/한자», device=pc+mo, ages — срез по возрастам (наша аудитория vs 성인 한자-аудитория). Лимиты: DataLab 50 000 вызовов/мес (HUB) / 25 000 (Developers legacy).

**Первый срез (2026-10-13, помесячно, пик группы = 100):** jlpt avg 49.8, сезонные пики 80–100 (янв — результаты декабрьской; апр — регистрация июльской; авг–сен — регистрация декабрьской), дно фев–май (24–34); 일본어 공부 avg 4.9 стабильно; 한자 공부 2.4; 일본어 어пл ~0.8. Сезонная модель подтверждена Naver-данными: JLPT-контент (일정/접수) обновлять к сентябрю и марту. Полный срез: `marketing/ko/research/2026-10-13-naver-datalab-slice.md` (маркетинг-репо).

## 4. Bing Webmaster (абсолюты прокси-Google)

Ключ в uwuwu-вики (в чат не тащим). `GetKeywordStats`, `country=kr`, `language=ko-KR` (дефис обязателен, §15.2). Данные за ~25-дневное окно ≈ месячная частота Google-базы. База §15.2: jlpt 14 832 imp (~17.8K/мес), 일본어 공부 1 909, jlpt 접수 1 173 (сент–окт), jlpt 일정 842. Обновлять раз в квартал или перед сезонной кампанией.

## 6. Wikipedia pageviews — якорь информационного спроса

`wikimedia.org/api/rest_v1/metrics/pageviews/per-article/ko.wikipedia/...` (без ключа). Окно брать **полными месяцами** (хвост месяца с нулями ломает тренд). Срез 2025-10…2026-09: 일본어 ≈ 3 096/мес · 히라가나 ≈ 2 666 · 가타카나 ≈ 1 603 · 일본어능력시험 ≈ 1 (мёртвая — не использовать как якорь JLPT; JLPT-спрос живёт в поиске латиницей).
