## 1. Главные выводы (EN)

1. **Origa отсутствует в топ-10 по всем 133 проверенным keywords**, включая все 48 целевых запросов 12 EN-постов. Посты при этом **проиндексированы** (`site:origa.uwuwu.net/blog` подтверждён независимым веб-поиском; бренд-запрос «origa japanese learning app» даёт наш пост на #1). Вывод: **это не проблема выбора ключей и не проблема контента — это проблема авторитетности домена** (~3 месяца, слабый бэклинк-профиль).
2. **Сама стратегия ключей подтверждена.** 61 из 71 валидных SERP-проверок — LOW difficulty: топ-10 принадлежит Reddit (90 вхождений), маленьким блогам и YouTube, а не большим брендам. Ниша виннабельна — **когда вырастет авторитет**.
3. **Кого придётся обходить** (владельцы выдачи): reddit.com (90 вхождений в топ-10), play.google.com (51), apps.apple.com (44), youtube.com (44), tofugu.com (27), migaku.com (24). Сторы доминируют в чистых «app»-запросах — вход через информационные long-tails, как и предсказывал pre-launch отчёт.
4. **Модификаторы спроса** (доля от 1181 собранных подсказок): `best` 11%, `free` 9%, `reddit` 6%, `anime/manga` 6%, `ai` 3%, `offline` 3%, `for beginners` 2%, `for pc/windows` 2%.
5. **Найдены контент-гэпы** — темы с подтверждённым спросом, не закрытые ни одним постом: `japanese learning app for pc free` (частота 6 — десктоп-версия Origa есть, поста нет), `japanese learning app better than duolingo` (5) + `not duolingo` (4), `is kanji hard to learn` (5).

**RU-прогон (детали §10):** Яндекс-выдача по 101 RU-keyword — **100% LOW difficulty** (мягче всех рынков: TikTok/YouTube/blogspot, ни одного сильного текстового конкурента); «с нуля» — супердоминанта (16% модификаторов, в 8× чаще чем beginners в EN); **оффлайн-интент в RU-подсказках = 0%** (в EN 3%); кластер-гэп «кандзи н5» (список/тест/учить); Яндекс-аудитория ищет «для русских» и «уроки». Origa: 0 топ-10 в Яндексе — та же проблема авторитетности домена. Google-mix SERP по RU остался недоступен (rate-limit движков) — некритично, Яндекс ≈ 2/3 рынка.

## 2. Источники данных: что именно измеряет каждый

| Источник | Что измеряет | Ось | Точность |
| --- | --- | --- | --- |
| **Google Suggest API** (`suggestqueries.google.com`, hl/gl по рынку) | Реальные запросы пользователей: в подсказках появляются только запросы с ненулевым объёмом; **порядок подсказок отражает относительную популярность** | **Спрос** | относительная (бинарно + порядок) |
| **Кросс-seed частота** (агрегация) | Сколько разных seed-запросов породили одну подсказку — интегральный сигнал «жирности» запроса | **Спрос** | относительная |
| **Wikipedia pageviews API** (wikimedia.org) | Точные просмотры статей — якорь информационного спроса на тему | **Спрос** | точные цифры, но по Wikipedia |
| **Bing autosuggest** (`api.bing.com`) | Кросс-проверка существования запроса | Спрос | бинарная |
| **Yandex Suggest** (`suggest.yandex.ru`) — только RU | Нативный спрос Яндекса (≈2/3 российского поиска) | **Спрос (RU)** | относительная |
| **Naver Suggest** (`ac.search.naver.com`) — только KO | Нативный спрос Naver (~50%+ корейского поиска) | **Спрос (KO)** | относительная |
| **SearXNG, пер-движковые проходы** (`engines=google cse` / `bing` / `yandex`) | Состав топ-10 и позиция Origa **в каждом движке отдельно**: Google-прокси + Bing (питает ChatGPT-поиск и DDG → GEO-ценность) + Яндекс (RU) | **Конкуренция** | прокси, per-engine |
| **Независимый websearch** | Бренд-чек, индексация (`site:`) | Диагностика | точная |
| Google Trends | Относительные объёмы во времени | Спрос | ❌ 429 — исключён из итерации |

**Ключевое разделение осей:**

- **Популярность (спрос)** — учтена, но **относительная**: Suggest говорит «этот запрос ищут и он популярнее того», но не «сколько раз в месяц». Абсолютные объёмы дают только Wordstat/Keyword Planner — оба требуют аккаунтов и недоступны автономно (см. §7).
- **Конкуренция (SERP)** — отдельная ось: кто стоит в топ-10 и какова там позиция Origa. К спросу отношения не имеет.
- **Приоритет keyword = спрос-сигнал × виннабельность**, а не объём в абсолюте.

## 4. SERP-проверка (SearXNG, пер-движковые проходы, топ-10)

Два независимых прохода по 133 keywords: **google-mix** (движок по умолчанию, прокси Google) — 126/133 валидно; **bing** (`engines=bing`) — 113/133 валидно (20 запросов попали под rate-limit движка). Difficulty-прокси = состав топ-10: форумы/малые блоги («other») = виннабельно; большие бренды/сторы = тяжело.

### 4.1 Difficulty: Google vs Bing

| Difficulty | Google-mix (126) | Bing (113) |
| --- | --- | --- |
| LOW | 100 (79%) | 108 (96%) |
| MED | 10 | 2 |
| LOW-MED | — | 3 |
| HIGH | 16 | 0 |

Long-tail в Bing ещё мягче (ни одного HIGH среди валидных). Расхождения по целевым ключам постов: `japanese flashcards app` (G:HIGH / B:LOW — в Google сторы владеют, в Bing нет), `learn hiragana` (G:MED / B:LOW), `jlpt n5` (G:LOW / B:MED). Среди целевых ключей постов HIGH в Google только у `japanese flashcards app`. Всё остальное, что таргетит блог — LOW — **выбор ключей верный, подтверждено двумя движками**.

### 4.2 Позиции Origa

| Движок | Топ-10 |
| --- | --- |
| Google-mix (126 keywords) | 0 |
| Bing (113 keywords) | 0 |
| Независимый websearch (выборочная верификация) | 0 из 2 (`japanese ocr app`, `anki alternative japanese reddit` — оба чисто Reddit/форумы/сторы в топе) |

Зона 11–30 (quick wins) массово не измерена — в очереди.

**Важная методологическая оговорка:** SearXNG-прокси **не видит наш домен даже по бренд-запросу** («origa japanese learning app» → origa #None), хотя независимый websearch даёт наш пост #1 по тому же запросу. Значит: позиция из SearXNG — **сигнал нижней границы** (увидел = точно есть; не увидел = неопределённо, реальная позиция может быть лучше). Вердикт «не ранжируемся по небрендовым запросам» подтверждён кросс-чеком независимого бэкенда по выборке; точные позиции даст только GSC.

### 4.3 Владельцы выдачи

Google-mix: reddit.com (90 вхождений в топ-10), play.google.com (51), apps.apple.com (44), youtube.com (44), tofugu.com (27), migaku.com (24). Bing: en.wikipedia.org (80), nhk.or.jp / tofugu.com / duolingo.com / wikipedia-версии (по 40), support.google.com (34) — Bing-лонгтейл мягче и «энциклопедичнее».

### §15.3 Bing Webmaster API — рабочий метод (для повторных замеров)

Актуальная база: `https://ssl.bing.com/webmaster/api.svc/json/{Method}?apikey=<ключ>&...` (старый `api.bingwebmaster.azure.com` — NXDOMAIN с 2026-09-18; `www.bing.com/webmasters/api/*` — внутренний XHR, apikey не принимает). Ключ — у владельца (фиксация в uwuwu-вики, в публичный репо не класть). Проверенные методы: `GetUserSites`, `GetQueryStats`, `GetKeywordStats` (параметры `country=us&language=en-US` — language строго с дефисом; возвращает Impressions/BroadImpressions по дням), `GetLinkCounts`. Замеры §15.2 сделаны им же. Официальная дока: learn.microsoft.com/en-us/bingwebmaster (SOAP/POX ретирятся 31.08.2026).
