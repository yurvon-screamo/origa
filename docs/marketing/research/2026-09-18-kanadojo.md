# Конкурентный анализ: KanaDojo (kanadojo.com) — 2026-09-18

Серия конкурентных разборов (см. также `2026-09-18-naminori.md`).

---

## TL;DR

**KanaDojo** — бесплатная веб-платформа-игра для тренировки каны/кандзи/лексики, «Duolingo × Monkeytype», **без грамматики и без настоящего SRS-курса**. Англоязычный глобальный рынок, аккаунт не нужен. Это **не прямой конкурент Origa по продукту** (другой сегмент: дрилл-игра для новичков, а не курс), но **самый успешный из трёх разобранных конкурентов по traction'у**: 3.4k GitHub-звёзд, 3.3k форков, 35k коммитов, спонсорство Vercel OSS, iOS/Android приложения. Главный урок — их **growth-машина** (OSS-комьюнити + SEO + LLM-SEO + zero-friction), а не функциональность.

## Карта продукта

**Три додзё:** Kana (хирагана/катакана), Kanji (JLPT N5–N1), Vocabulary.
**Режимы:** Pick, Reverse-Pick, Input, Reverse-Input, Blitz (на время), Gauntlet (выживание, ошибки отнимают жизни), Kana Rain (анимация). Сессии-минутки в стиле Monkeytype.
**«Smart repetition»**: запоминает точность по каждому знаку и чаще показывает проблемные — **это НЕ FSRS**, просто accuracy-weighted повторение. Курса, расписания, интервалов нет.
**Геймификация:** стрики, 80+ ачивментов, GitHub-style календарная сетка активности, конфетти, 100+ тем, 28 японских шрифтов, премиум-обои (Киото, Арасияма...), сезонные темы (рождественская с Mariah Carey).
**Инструменты (SEO/утилиты):** /translate (EN↔JA + ромадзи, клиентский Kuroshiro/Kuromoji), **/conjugate** (спрягатель глаголов), /kana-chart, **/anki-converter** (клиентский, SQL.js/WASM).
**/academy:** ~80 SEO-статей — listicles («Best free apps 2026», где сами №1), **vs-страницы** (kanadojo-vs-kana-pro, kanadojo-vs-realkana, best-duolingo-alternatives), JLPT-гайды, тематическая лексика (еда, семья, цвета), культурные (суеверия, сленг, аниме). Плюс программные страницы /jlpt/n5-n3, /hiragana-practice и т.д.
**Приложения:** iOS + Android (пока только кана), PWA.

## Growth-машина (настоящий актив)

1. **OSS-комьюнити как дистрибуция**: AGPL-3.0, hacktoberfest-топики, «good first issues», гайд для полных новичков, Discord. 3.3k форков = сотни контрибьюторов-евангелистов. Vercel OSS Program спонсирует хостинг
2. **SEO-машина**: vs-сравнения с конкурентами по брендовым запросам, листиклы со своим №1, программные JLPT/практика-страницы, IndexNow (TODO в репо), sitemap
3. **LLM-SEO**: robots.txt явно разрешает GPTBot/Claude/Perplexity/CCBot/Google-Extended — их контент скармливается ИИ-поисковикам (ср. с нашей доктриной «лендинг = LLM-facing surface»)
4. **Zero-friction**: аккаунт не нужен, «start learning now», офлайн-PWA
5. Рецепция: Reddit-посты основателя в r/LearnJapaneseNovice, Medium-обзоры, App Store/Google Play (кана-приложения)

## Что забрать / что нет

**Кандидаты:**
1. **Мини-игровые режимы поверх существующего контента** (Blitz = на время/счёт, Gauntlet = 3 жизни) — идеально ложится в нашу тап-философию и переиспользует наши же уроки; это вовлечение, а не новый контент. (Осторожно: 3D-ферму юзер уже отверг — это ДРУГОЕ: не виртуальный мир, а модификаторы той же сессии)
2. **Публичные утилиты на лендинге с реальной пользой**: спрягатель глаголов — у нас ГОТОВЫЙ движок форм (`domain/grammar/forms_verb`) и lindera; это программный SEO с utility, сильнее контентных страниц. Счётчики, кана-таблица — туда же
3. **LLM-SEO**: проверить robots.txt нашего лендинга на допуск GPTBot/Claude/Perplexity — дёшево, соответствует доктрине
4. **Anki-конвертер/импорт как воронка** — у нас импорт уже есть (#424); идея — сделать его заметным на лендинге как «перенеси свой Anki»

**Не забирать:** 100+ тем/шрифтов/обои (против нашего дизайн-языка Cormorant+DM Mono); OSS-комьюнити-модель (репо приватный, BSL — осознанное решение); accuracy-weighted «SRS» (наш FSRS строго лучше); энциклопедичность инструментов (translate — не наша борьба).
