# App Store KR: срез витрины + заметки по методу (2026-10-12)

Автор: @ko. Задача лида: срез своей витрины (country=kr) — suggestions + позиции Origa + плотность конкурентов. Внешний доступ не нужен: срез сделан безключевым iTunes Search API; ASC API (показы/конверсии/popularity) — ждёт ключ от владельца, см. §5.

## 1. Метод (заметки по инструменту)

- Endpoint: `https://itunes.apple.com/search?term=<seed>&country=kr&lang=ko_kr&entity=software&limit=100`.
- **`entity=software` обязателен**: без него выдача замешивает фильмы/подкасты/книги, и позиции бессмысленны (первый прогон без entity показал подкасты по термину «origa»).
- `limit` ≤ 200; позиция Origa = индекс `bundleId == net.uwuwu.origa` + 1.
- Стабильный и анонимный; задержка ~1 с между запросами. Скрипт: `marketing/ko/scripts/aso_kr.py` (marketing-репо, сырой JSON — `/tmp/opencode/aso_kr_slice.json`, в репо не тащу).
- **Suggestions (подсказки поиска App Store) публичным API не отдаются** — поле popularity живёт в App Store Connect API (`App Analytics → Search popularity`). Без ASC-ключа подсказки снимаются только вручную из клиента стора; в срез их не включал.

## 2. Базовые факты

- Приложение в KR-витрине есть: **«Origa - JLPT Learn Japanese»** (`net.uwuwu.origa`), 0 оценок.
- Брендовый поиск «origa» (entity=software): **позиция 3** в KR и US — уступает origami-шуму («Paper Fold», «Origami Master»), но находимы. В NAME-ранжировании это норм для 0-review приложения.

## 4. Выводы

1. **ASO-видимость нулевая по всем money-сидам** — не в топ-100 нигде, кроме хвоста «jlpt» (94). При 0 оценок это ожидаемо, но сиды из тренд-среза (일본어 공부 어플 = топ-1 Naver-подсказка; jlpt-кластер) — это готовый список таргетов: имя/подзаголовок/ключевые слова стора должны содержать 일본어 공부, JLPT, 한자, 히라가나.
2. **Конкурент-сет стабильный**: 듀오링го, 일단공부, MARU일본어 첫걸음, 똑똑보카, HelloTalk, 이로이로, HeyJapan, YuSpeak, JPmate, Migii, 해커스. Их общий знаменатель — карточки с корейским подзаголовком и локализованными скриншотами; наш подзаголовок на английском («JLPT Learn Japanese») в KR-витрине — прямая потеря релевантности.
3. **Свободная жила**: ни один из топов не показывает on-device OCR/офлайн-дифференциатор — карточные ключи «사진으로 단어장», «오프라인 일본어 공부» не заняты никем из видимых. Проверять после ASC-ключа по popularity; пока — кандидат в keyword-поле.
4. **0 оценок** — блокер конверсии сильнее позиций: первые KO/глобальные_review-кампании (TestFlight→оценки) дают больше, чем любая ASO-механика.
5. Латинский «jlpt» (тренд-срез) в сторе подтверждается: сид «jlpt» выдал 95 приложений — ключевое слово стоит писать латиницей и хангылем.

## 5. Что даст ASC API ключ (в списке доступов босса)

- Search popularity по сидам (реальные частоты витрины) — уберёт гадание по подсказкам.
- Показы/просмотры/загрузки с разбивкой по источникам (App Store search vs browsing) и по storefront — прямой ответ «кто нас ставит» на сторе, аналог GSC.
- Процедура: App Store Connect → Users and Access → Integrations → API ключ (Admin) → `marketing/.env` (ISSUER_ID, KEY_ID, .p8 файл).
