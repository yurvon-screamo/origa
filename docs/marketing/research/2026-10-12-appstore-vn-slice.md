## Главная находка

**Origa есть на VN-витрине:** `Origa - JLPT Learn Japanese` (id 6795012532, dev «yurvon screamo»), 0 оценок. По брендовому запросу «origa» — ранг **45** (выдача забита origami-приложениями). По всем 9 контентным сидам — отсутствует в топ-50.

## Выводы для ASO (продуктовой стороне)

1. **Связующее ограничение — не ключи, а рейтинг и установочная скорость**: 0 оценок гарантированно держит Origa вне топ-50 при любых ключах. Первый рычаг — начальный пул оценок и конверсия установки, второй — ключевое поле.
2. **Заголовок «Origa - JLPT Learn Japanese» целится в меньший кластер**: JLPT на VI-витрине уже занят местным Migii, а главный трафик-кластер — «Học tiếng Nhật» в точном вхождении (Mikun выигрывает именно этим). Для VI-витрины кандидат: вынести «Học tiếng Nhật» в заголовок/подзаголовок, JLPT — в ключи. Решение продуктовой стороне, не маркетингу.
3. **«hán tự» как ключ бесполезен** (перехвачен hanzi-приложениями); в ключевые поля — «học kanji», «kanji n5», «jlpt n5».
4. **Миграционный угол**: HeyJapan/Mazii/Mikun — аудитория, которую умеем забирать (Anki-импорт, OCR-фичи); следить за их ревью — источник возражений (по аналогии с kanadojo.md-разбором).

## Ограничения метода

- iTunes Search API отдаёт до 50 результатов на запрос; полная глубина выдачи не видна.
- Популярность ключей и показы — только через ASC API (App Store Connect Analytics), ключ у босса в очереди.
- Suggestions витрины (404 из скрипта) — через ASC тоже.
