# ADR-052: GeoIP-база для гео-обогащения логов TrailBase — источник и провижининг

- Статус: Принято
- Дата: 2026-09-13
- Контекст: PR #532; развёртка в прод выполнена вручную до мержа (railway ssh + redeploy)

## Контекст

TrailBase показывает страны клиентов в админ-логах (`/_/admin/logs`), если в
traildepot лежит MaxMind-совместимая база `<traildepot>/GeoLite2-Country.mmdb`.
База загружается один раз при старте процесса; гео вычисляется **на лету при
просмотре** (`geoip_country(client_ip)` подставляется в SQL в
`list_logs.rs`/`stats.rs`), поэтому свежая база покрывает и исторические записи.

Критичное ограничение апстрима: SQL-функции гео активируются только при
`database_type` ∈ {`GeoLite2-Country`, `GeoLite2-City`, `GeoLite2-ASN`}
(`crates/extension/src/geoip.rs::database_type`). Любая другая строка в
метаданных → `DatabaseType::Unknown` → гео-колонка не появляется вовсе.

Регистрация на MaxMind для бесплатной GeoLite2 **недоступна из РФ** (EULA-блок
по стране: «We're not able to offer GeoLite access from your country»).

## Рассмотренные альтернативы

| Вариант | Почему отвергнут |
|---|---|
| MaxMind GeoLite2 напрямую | Регистрация гео-блокирована для РФ |
| DB-IP Country Lite (CC BY 4.0, без аккаунта) | `database_type: "DBIP-Country-Lite"` → `Unknown` у TrailBase, гео не активируется |
| Байт-патч строки `database_type` в DB-IP mmdb | Строки разной длины (17 vs 16) → перепаковка метаданных; в контейнере нет python/go; ложная атрибуция данных в админке |
| Патч форка TrailBase (принять `DBIP-Country-Lite` в матчер) | Честно, но требует пересборки форка (submodules + pnpm + protoc); отложено как возможный upstream-PR |

## Решение

Источник — [P3TERX/GeoLite.mmdb](https://github.com/P3TERX/GeoLite.mmdb):
еженедельный репаблиш официальной GeoLite2-Country в готовом mmdb, фиксированный
URL `releases/latest/download`, без аккаунта. Метаданные несут честный
`database_type: "GeoLite2-Country"` → гейт TrailBase проходит нативно.

Лицензионный нюанс принят осознанно: репозиторий — сторонний редистрибьютор
GeoLite2-данных (MaxMind EULA формально ограничивает redistribution).
Атрибуция MaxMind сохраняется внутри метаданных файла; использование —
внутренняя статистика логов, не пользовательский продукт.

Провижининг — по образцу существующего backup-механизма образа `origa_ui`
(`crond` + `entrypoint.sh` + `crontab`):

- `geoip.sh` — атомарная загрузка (tmp → `mv`), skip при свежести (окно 6 дней
  против еженедельного крона — скип никогда не «залипает»), size-guard от
  битых/усечённых файлов (включая уже существующие), retry на транзиентные
  сбои, fail-open: сбой загрузки никогда не блокирует старт контейнера;
- entrypoint вызывает до `exec trail` (бюджет 45 с, уложен в окно healthcheck),
  свежий volume получает гео с первого бута;
- crond обновляет еженедельно (пн 06:17 UTC); обновлённый файл подхватывается
  при следующем рестарте — TrailBase грузит базу при старте, хот-релоада нет.

## Семантика client_ip за инфраструктурой (верифицировано на проде)

- VPS reverse-proxy (`app.origa.uwuwu.net` → Aeza → Railway, см. ADR-049)
  перезаписывает `X-Forwarded-For` адресом подключившегося; Railway ничего не
  дописывает; TrailBase берёт rightmost-XFF → **прямые пользователи логируются
  реальными IP** (доказано маркерным тестом с фейковым XFF).
- Клиенты за обходными туннелями (xray, выходы Datacamp AS60068 с ротацией на
  каждое соединение) логируются IP/страной выходного узла — присущая интернету
  семантика VPN, серверно не лечится. В списке логов такая сессия выглядит
  «пёстрой» (каждая строка — страна очередного выхода).

## Последствия

- Потеря volume → база перекачается автоматически при следующем старте.
- Исчезновение/деградация P3TERX-репозитория → гео молча пропадёт после
  устаревания базы (fail-open); миграция на другой `GeoLite2-*`-совместимый
  источник — смена `GEOIP_URL` в `geoip.sh`.
- Долгосрочная альтернатива без third-party-зависимости — upstream-PR в
  TrailBase с расширением матчера `database_type` (например, принятие
  `DBIP-Country-Lite`), после чего источником становится DB-IP Lite без
  аккаунта и EULA-серых зон.
