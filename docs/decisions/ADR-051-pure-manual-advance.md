# ADR-051: Pure-manual advance для feedback-карточек урока

- Статус: Принято
- Дата: 2026-09-13
- Контекст: документация существующего контракта + исправление фиктивных
  цитат «ADR-033» (этот ADR — канон, см. «Историческая справка»)

## Контекст

Первоначально после ответа на квиз-подобную карточку урок автоматически
переходил к следующей по таймеру 1500 мс. Юзер-репорт: «застревание на
окне ответа» — таймер конфликтовал с чтением вердикта и разбора
(правильный ответ, дистракторы), и переход случался либо раньше, чем
юзер дочитал, либо подвисал.

Feedback-карточки отличаются от рейтинг-карточек тем, что после ответа
на экране появляется **вердикт** («Правильно/Неверно», правильный ответ,
разбор) — информация, ради которой карточку стоит удержать.

## Решение

Две модели перехода к следующей карточке:

1. **Immediate** (рейтинг без вердикта): Normal / Reversed / Writing, а
   также AudioRecall (исключение, выведено из модели 2 отдельным
   решением — ADR-050). Ответ/самооценка рейтингует через общий
   `on_rate`-пайплайн и сразу переводит к следующей карточке.
2. **Pure-manual advance** (feedback с вердиктом): Quiz,
   KanjiReadingQuiz, GrammarQuiz (все через `QuizCardView`), YesNo,
   PhraseListen и multi-quiz. После ответа карточка удерживается:

   - состояние: `waiting_for_next = true` + `pending_rating = Some(..)`;
   - закрытие: Space, Enter или любая цифра (0–9) с клавиатуры либо
     кнопка «Далее» (`NextCardButton`, `lesson-card-next-btn`);
   - таймера нет — единственный путь вперёд ручной.

Инварианты:

- Каждый `on_*`-хендлер, флипающий `waiting_for_next`, ОБЯЗАН ставить
  `pending_rating` (контракт `on_next_card`; в debug — ассерт, в release
  fallback `Rating::Again` — консервативнее для FSRS, чем молча
  завышенный `Good`).
- Гейт CI: `skipped` легален только при path-skip; skip при `run=true`
  роняет CI Gate (не связано с advance напрямую, но тот же принцип
  fail-closed).

## Последствия

- Юзер сам задаёт темп чтения вердикта; «застревание» исчезло вместе с
  таймером.
- e2e-хелперы (`completeLessonFlexible`) закрывают feedback-карточку
  кликом `lesson-card-next-btn` до остальных интеракций.
- Историческая справка: комментарии к коду ссылались на «ADR-033» как на
  источник этой модели — фиктивно (реальный ADR-033 — «Apple platforms:
  Mac App Store only distribution»). Контракт до этого ADR нигде не был
  задокументирован; фиктивные цитаты исправлены на ссылки сюда (PR с
  этим ADR), ADR-050 описывает исключение AudioRecall.
