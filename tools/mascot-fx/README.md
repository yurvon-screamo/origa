# mascot-fx

Code-driven pixel-art animations of the Origa mascot, built with the
[pixelfx](https://github.com/patch-gg/pixelfx) method (Hugo Duprez's
"code is clay, trust your eyes, feed your references"). **Dev-only**: this
tool renders assets; nothing here ships to the app runtime.

## Layout

- `mascot/palette.js` — the 13-color Origa palette (single source of truth;
  parsed from `origa_ui/public/logo.png`, do NOT trim colors to save bytes)
- `mascot/origa.js` — the mascot as ASCII-matrix sprite, 64×96, poses
  `idle` / `blink`; generated by `scripts/build_sprite_matrix.py`
- `fx/*.js` — scenes composing the mascot with library effects
- `scripts/sprite_from_image.py` — image-to-matrix pipeline (integer cell
  downscale + majority snap to the palette + corner flood-fill + halo grow)
- `export.mjs` — batch export: lossless WebP @12/8 fps + still PNG +
  `manifest.json`
- `check-scenes.mjs` — determinism + per-frame cost check (< 2 ms)
- `demo.html` — local gallery, open in a browser

## Method (per scene)

1. Reference first: read the closest library effect (`src/fx/...`) before
   writing; benchmark your render next to it at the same height.
2. Render and look: `node export.mjs <scene>`, then open the frames under
   `records/export-<scene>/` (or `demo.html` for motion).
3. Fix the worst thing, render again — three rounds minimum.
4. `node check-scenes.mjs` must pass clean.

## Export contract

- Frames render in the scene's own world, then upscale by an INTEGER factor
  (`zoom: 2`) — fractional scaling blurs the pixel grid.
- Destinations: app → `origa_ui/public/mascot/`, landing copies →
  `origa_landing/public/images/mascot/`, marketing-only (streak) →
  `assets/` — **marketing assets never ship inside the product** and don't
  count against the weight budget.
- Budgets: per-scene (see `export.mjs`) and ≤600 KB shipped total; on
  overflow drop fps 12→8 first, then trim frames/duration, never the palette.
- `manifest.json` lands in `origa_ui/public/mascot/` and is asserted by the
  Rust test in `mascot_animation.rs` (fps, frame size, budgets) — if that
  test fails, the export pipeline and the UI component have drifted.
