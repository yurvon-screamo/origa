# 実際に必要な漢字の数：正直な数字

「日本語には2,136の文字がある」。この一文は初心者を最も怖がらせてきました。技術的には正しく、実用的には無意味です: 常用漢字2,136は新聞を読むための量であって、言語の参入障壁ではありません。

正しい問いは: **あなたの**目的には何個の漢字が必要か。答えは具体的な数字で、恐ろしい数字よりはるかに下です。

## まず、出典についての注意

JLPTの主催機関は、どのレベルでも公式の漢字・語彙リストを公表していません。「N5 ≈ 100、N1 ≈ 2000」と書かれたすべての表は、過去問の分析から再構築された教師側の合意です。以下の数字はすべてこの留保付きで扱い、出典間の±20%のずれは正常と考えてください。

## 目的別のしきい値

| 目的 | 目安の漢字数 | おおよそのレベル |
| --- | --- | --- |
| 完全ふりがな付きの漫画（少年、日常系） | 100〜300 | N5〜N4 |
| 日常会話、キャプション、メニュー | 200〜400 | N4 |
| Web記事、簡単な物語 | 約700〜1,000 | N3 |
| 小説、字幕なしのテレビ | 約1,300〜1,800 | N2〜N1 |
| 新聞、公式文書 | 2,136常用漢字＋人名 | N1以上 |

観察が2つ。第一に: わずか数百文字で、ふりがな付き漫画は既に実物のコンテンツの実読に開きます。第二に: 「漫画を読む」と「新聞を読む」の間には10倍の差があり、ほとんどの学習者は遠い側を必要としません。漫画での始め方の詳細は[専門記事](/ja/blog/learn-japanese-from-manga)を参照してください。

## 「漢字を知っている」が間違った枠組みである理由

漢字は単独では存在しません。単語の中に生きています。食は食べる（たべる）、食事（しょくじ）、和食（わしょく）に現れ、それぞれ違う読み方をします。「漢字の食」を単独で学ぶことは、1週間で消える抽象概念を暗記することを意味します。

意味のある単位は文字ではなく**単語**です。300漢字は、それらを含む約900〜1,500語に換算されます。それらの単語を知ってしまえば、「ここではどの読みと意味が当てはまるか」は文脈から自動的に解決します。

実務的な結論: 目標は「Y漢字をカバーするX語の語彙」と定式化し、決して「漢字リストの暗記」とは定式化しないでください。裸の文字リストは、1か月を無駄にする最速の道です。

## そこへ至る方法

**自分のコンテンツから漢字を学ぶ。** 漫画や記事で出会った文字は、筋と文に結び付けられます。保持率はリストより劇的に良いです。

**間隔反復は交渉の余地なしです。** システムなしでは、昨日の単語は1週間で消えます。SRSがあれば、間隔は自動的に週、月へと伸びていきます。

### 1日に現実的に覚えられる漢字の数は？

単語を通してなら: 1日5〜10の新規単語は持続可能なペースで、漢字数は副作用として増えます。1日に裸の文字20個を磨くと、カウンターはきれいになりますが、1か月後の記憶は空です。

### 学んだ漢字は忘れますか？

はい、復習なしでは。間隔反復が伸びる間隔でアクティブに保ちます。「恒久的に」定着するのは、定期的な読むことだけです。

### ローマ字やひらがなで日本語の単語を書いてもいいですか？

ひらがななら、はい: ネイティブも一般的でない文字にはそうします。ローマ字なら、通じますが、テキストは異質に見え、読みに必要な文字認識のトレーニングになりません。
