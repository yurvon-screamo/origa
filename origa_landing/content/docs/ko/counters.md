# 일본 조수사

일본어는 사물을 조수사로 셉니다: 긴 물건은 本, 납작한 것은 枚, 작은 동물은 匹, 사람은 人. Origa는 각 접미사를 카드 하나로 다루고 그 안에서 두 종류의 지식을 훈련합니다.

## 접미사 하나가 카드 하나

조수사 카드는 접미사 자체 — 무엇을 세는지 — 와 숫자 결합형을 담습니다: 1부터 10까지의 읽기, 의문형 何, 그리고 10을 넘는 몇 굳어진 형태(이십일 같은 날짜, はつか로 읽음). 새 카드와 같은 인식 단계를 거칩니다: 소개 슬라이드에 접미사를 크게, 뜻을 사용 언어로, 불규칙 읽기가 강조된 전체 읽기 표를 보여줍니다.

## 의미와 결합형은 따로 나이를 먹는다

접미사의 의미("긴 물건: 연필, 병, 나무")는 다른 모든 카드와 같은 고전적인 **알겠다 / 모르겠다** 버튼으로 복습됩니다. 숫자 읽기 표(三本 → さんぼん)는 첫 만남의 인식 슬라이드, 훈련 답변, 조수사 페이지에 있으며 불규칙 읽기는 그곳에서 강조됩니다. 접미사를 "이미 압니다"로 표시하면 의미와 결합형을 함께 건너뜁니다.

일반 복습은 부호와 의미만 보여줍니다. 다른 모든 카드와 같은 앎 / 모름 흐름이며 읽기 표는 여기에 들어가지 않습니다.

## 조수사는 어디서 오나

조수사는 수준과 함께 옵니다: 온보딩 가져오기가 해당 JLPT 수준 이하의 접미사를 추가하고, 별도의 조수사 페이지가 전체 목록과 각 접미사의 상세 카드를 보여줍니다 — 직접 찾아보고 추가하고 복습할 수 있습니다. 텍스트에서 수사 결합 단어(一本)를 추가할 때도 조수사가 별도 후보로 제안됩니다. 이미 아는 접미사면 "이미 압니다"로 표시하세요 — 의미와 숫자 결합형 드릴을 함께 건너뜁니다. 조수사 이전에 만든 계정에는 업데이트 후 첫 실행 때 일회성 마이그레이션이 어휘가 이미 만난 접미사를 찾아 추가합니다.

데이터셋은 데이터 파일로 관리되며 흔한 교재가 다루는 접미사를 JLPT 수준별로 편집자 합의로 묶습니다 — 공식 JLPT 조수사 목록은 없습니다. 뜻풀이는 영어, 러시아어, 한국어, 베트남어로 유지됩니다. 출처는 [데이터 출처](/ko/docs/data-sources) 페이지를 보세요.
