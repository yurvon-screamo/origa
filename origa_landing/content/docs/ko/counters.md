# 일본 조수사

일본어는 사물을 조수사로 셉니다: 긴 물건은 本, 납작한 것은 枚, 작은 동물은 匹, 사람은 人. Origa는 각 접미사를 카드 하나로 다루고 그 안에서 두 종류의 지식을 훈련합니다.

## 접미사 하나가 카드 하나

조수사 카드는 접미사 자체 — 무엇을 세는지 — 와 숫자 결합형을 담습니다: 1부터 10까지의 읽기, 의문형 何, 그리고 10을 넘는 몇 굳어진 형태(이십일 같은 날짜, はつか로 읽음). 새 카드와 같은 인식 단계를 거칩니다: 소개 슬라이드에 접미사를 크게, 뜻을 사용 언어로, 불규칙 읽기가 강조된 전체 읽기 표를 보여줍니다.

## 의미와 결합형은 따로 나이를 먹는다

접미사의 의미("긴 물건: 연필, 병, 나무")와 숫자 결합형(三本 → さんぼん)은 서로 다른 복습 일정을 따릅니다. 일반 복습에서는 **알겠다 / 모르겠다**로 의미를 평가하거나, 수업이 결합형 묶음을 냅니다: 숫자와 접미사가 보이고 올바른 읽기를 고르는 짧은 질문들의 연속입니다. 각 결합형은 자기 답을 기억하므로 いっぽん, さんぼん, ろっぽん 같은 불규칙 읽기가 규칙적인 것보다 자주 돌아오고, 굳어진 규칙형은 순환에서 빠져나갑니다.

묶음의 매 답변 뒤에는 접미사 전체의 읽기 표가 나오고 방금 답한 행이 강조됩니다. 처음 만났던 같은 표가 이제 피드백으로 쓰이는 것입니다.

## 조수사는 어디서 오나

조수사는 수준과 함께 옵니다: 온보딩 가져오기가 해당 JLPT 수준 이하의 접미사를 추가해 인식 풀이 점진적으로 만나게 합니다. 이미 아는 접미사면 온보딩 평가에서 표시하세요 — 의미는 훈련을 건너뛰지만 숫자 결합형 드릴은 남습니다. 조수사 이전에 만든 계정에는 추가한 단어에 나타나는 접미사(단어 一本이 本을 불러옴)를 찾아 그 수준의 나머지와 함께 카드를 만듭니다.

데이터셋은 저장소에서 관리되며 흔한 교재가 다루는 접미사를 JLPT 수준별로 편집자 합의로 묶습니다 — 공식 JLPT 조수사 목록은 없습니다. 뜻풀이는 영어, 러시아어, 한국어, 베트남어로 유지됩니다. 출처는 [데이터 출처](/ko/docs/data-sources) 페이지를 보세요.
