# Origa 문서

Origa의 작동 방식과 사용법을 다루는 안내입니다.

## 시작하기

처음 오셨다면 여기부터 시작하세요. 설치, 로그인, 초기 설정, 첫 레슨, 직접 카드를 추가하는 방법을 다룹니다.

→ [시작하기](/ko/docs/getting-started)

## 기능별

- **[레슨](/ko/docs/lesson):** 레슨에 무엇이 들어가는지, 새 카드의 익히기 단계, 카드 유형, 평가 방식, 간격 반복이 복습 일정을 세우는 원리.
- **[조수사](/ko/docs/counters):** 조수사(本, 枚, 匹)를 어떻게 배우는지: 의미와 숫자 결합형, 접미사 하나가 카드 하나.
- **[Origa가 무엇을 보여줄지 정하는 방법](/ko/docs/fsrs):** 망각 곡선, FSRS, 페이스와 일일 한도. 카드가 왜 다 떨어지는지, 그리고 왜 그것이 정상인지.
- **[어휘](/ko/docs/vocabulary):** 내장 사전, 오디오 발음, 카드를 추가하는 네 가지 방법, 미리 구성된 단어 세트.
- **[한자](/ko/docs/kanji):** 익히면 숨겨지는 자동 후리가나, 획순으로 하는 쓰기 연습, JLPT 수준별 한자.
- **[문법](/ko/docs/grammar):** 이미 알고 있는 어휘로 만든 예문과 함께, JLPT 수준별로 정리된 참조.
- **[문장과 듣기](/ko/docs/phrases):** 원어민 문장과 원본 오디오, 수준에 맞게 자동으로 선택.
- **[캡처](/ko/docs/capture):** 기기 내 OCR과 음성 인식. 사용법, 모델이 다운로드되는 시점, 알려진 한계.

## 참고

- **[제약 사항](/ko/docs/limitations):** Origa가 오늘 하지 못하는 일을 있는 그대로 적었습니다.

## 이 문서가 다루지 않는 것

이 문서는 Origa의 작동 방식과 사용법을 설명합니다. 다른 앱과의 비교가 아닙니다. 비교는 [비교 페이지](/ko/compare)를 참고하세요. 릴리스 노트나 변경 이력도 아닙니다. 그것들은 GitHub에 있습니다.
