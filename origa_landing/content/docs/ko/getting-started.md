# 시작하기

Origa는 기기에서 작동하는 일본어 학습 앱입니다. 이 안내는 첫 세션을 처음부터 끝까지 따라갑니다: 설치, 로그인, 수준 설정, 어휘 가져오기, 첫 복습 완료.

설정 대부분은 한 번만 하면 됩니다. 첫 로드가 끝나면 Origa는 오프라인으로 작동합니다.

## 1. 설치

Origa는 Windows, Linux, macOS, Android에서 쓸 수 있습니다. 웹 버전도 브라우저에서 작동합니다.

[다운로드 →](/ko/download)

플랫폼에 맞는 패키지를 고르세요. 데스크톱에서는 설치 프로그램이 Origa를 응용 프로그램 폴더에 놓습니다. Android에서는 시스템이 물으면 설치를 허용하세요.

## 2. 로그인

첫 화면은 로그인을 요청합니다. Google이나 Yandex 계정으로, 또는 이메일과 비밀번호로 로그인할 수 있습니다.

게스트 모드는 없습니다. 계정이 필요한 이유는 Origa가 학습 진행 상황을 기기 간에 동기화하고 어디까지 했는지 기억하기 때문입니다. 처음 로그인할 때 프로필이 자동으로 만들어집니다.

인터페이스 언어는 로그인 화면이나 첫 온보딩 단계에서 바꿀 수 있습니다.

## 3. 초기 설정

첫 로그인 후 Origa는 짧은 설정을 엽니다. 끝까지 진행해도 되고 건너뛰어도 됩니다. 다만 건너뛰면 첫 레슨이 비어 있습니다. Origa가 보여줄 카드가 아직 없기 때문입니다.

설정은 네 가지를 다룹니다:

- **언어.** 인터페이스와 번역 언어를 고르세요: 한국어, 영어, 러시아어, 베트남어.
- **페이스.** 하루에 새 카드를 몇 장 배울지 최소부터 최대까지 고르세요. 나중에 프로필에서 바꿀 수 있습니다.
- **수준.** 현재 JLPT 수준(N5부터 N1까지, 또는 "모름")을 알려 주세요. 그 수준 아래 내용을 이미 안다고 표시하면, Origa는 이미 익힌 것을 복습시키지 않습니다.
- **앱과 교재.** 다른 도구(Anki, Migii, Duolingo, Minna no Nihongo, Irodori)로 공부한 적이 있다면 선택하고 어디까지 했는지 표시하세요. Origa가 해당 어휘를 가져와서 빈 상태에서 시작하지 않게 됩니다.

설정이 끝나면 Origa가 필요한 사전, 한자, 문법, 문장 데이터를 내려받습니다. 이 단계에는 인터넷 연결이 필요합니다. 한 번 끝나면 연결 없이도 공부할 수 있습니다.

## 4. 첫 레슨

설정이 끝나면 홈 화면에 현재 JLPT 진행 상황과 오늘 예정된 것이 표시됩니다. 거기서 레슨을 시작하세요.

레슨은 카드의 연속입니다. 질문을 보고, 답을 확인하고, 알고 있었는지 평가합니다. 평가에 따라 간격 반복 스케줄러가 다음에 언제 이 카드를 보여줄지 정합니다.

오늘 새 카드가 있으면 레슨은 익히기 단계로 시작합니다: 새 그룹(후리가나와 번역이 붙은 단어, 한자, 문법)을 훑고, 곧바로 짧은 훈련을 돌립니다. 이 단계는 "복습으로" 화면으로 끝나고, 이후 레슨의 일반 부분이 시작됩니다. 자세한 내용은 [레슨 작동 방식](/ko/docs/lesson)을 참고하세요.

일반 부분은 두 버튼 평가를 씁니다: "모름" 또는 "알음"(익히기 훈련에서는 "기억함" / "기억 안 함"). 카드는 여러 모양으로 나옵니다: 인식(일본어 → 한국어), 회상(한국어 → 일본어), 듣기, 쓰기, 한자 읽기, 문법. Origa가 무엇을 배웠고 무엇이 복습 예정인지에 따라 구성을 고릅니다.

레슨이 끝나면 진행 상황이 서버로 동기화됩니다. 이어서 다른 레슨을 시작하거나 대시보드로 돌아갈 수 있습니다.

## 5. 직접 카드 추가하기

자기에게 필요한 것을 공부하는 가장 직접적인 방법은 직접 어휘를 추가하는 것입니다. 단어 화면을 열고 네 가지 방법 중 하나로 카드를 만드세요:

- **텍스트.** 일본어 단어나 문장을 입력하거나 붙여 넣으세요. Origa가 토큰화하고 번역을 찾아, 만들 수 있는 카드의 미리보기를 보여줍니다. 남길 것을 고르세요.
- **이미지.** 사진을 끌어다 놓거나 붙여 넣거나 파일을 고르세요. Origa가 기기에서 문자 인식(OCR)을 실행해 일본어 텍스트를 추출하고, 검토해서 추가합니다. 인식 모델은 이 기능을 처음 쓸 때 내려받습니다.
- **오디오.** `.wav` 녹음을 올리세요. Origa가 기기에서 음성 인식 모델로 전사하고 인식된 단어를 추가합니다. OCR과 마찬가지로 모델은 첫 사용 때 내려받습니다.
- **Anki 덱.** 기존 `.apkg` 파일을 가져오세요. Origa가 단어 필드와 번역 필드를 자동으로 찾아 카드를 들여옵니다.

네 방법 모두에서 Origa가 가능한 범위에서 발음(후리가나), 품사, JLPT 수준을 채웁니다. 중복 단어는 건너뜁니다.

## 6. 오프라인으로 되는 것

첫 설정 이후 Origa의 대부분은 인터넷 없이 작동합니다:

- 텍스트, 이미지, 오디오로 카드 만들기
- 레슨과 복습
- 간격 반복 스케줄링
- Anki 덱 추가
- 발음 듣기(TTS)

인터넷이 필요한 것:

- 처음 로그인
- 첫 실행 때 사전과 콘텐츠 내려받기
- OCR과 음성 인식 모델을 처음 쓸 때 내려받기
- 기기 간 진행 상황 동기화
- 앱 업데이트 확인
- 카탈로그에서 미리 구성된 어휘 세트 가져오기

오래 오프라인으로 있을 예정이라면(비행기, 긴 이동 시간) **프로필 → 오프라인 번들**을 열고 미리 전부 내려받으세요. 그 다음부터 인터넷을 쓰는 일은 계정 동기화뿐입니다.
