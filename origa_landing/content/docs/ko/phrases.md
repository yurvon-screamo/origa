# 문장과 듣기

Origa에는 원어민 일본어 콘텐츠에서 뽑은 문장 코퍼스가 들어 있습니다. 이 문서는 문장이 어디서 오는지, 어떻게 골라지는지, 듣기 연습이 어떻게 작동하는지를 다룹니다.

## 문장 코퍼스

코퍼스는 일본어 사용자가 일본어 사용자를 위해 만든 콘텐츠에서 뽑은 원어민 문장입니다. 출처에는 비주얼 노벨과 애니메이션이 있습니다. 각 문장에는 원래의 성우 녹음이 붙습니다. 원연주자가 녹음한 것이지 합성이 아닙니다.

이것은 실제 회화 일본어입니다. 표현, 억양, 어휘가 언어가 실제로 쓰이는 방식을 반영합니다.

## N+1 선택

문장이 레슨에 들어올 때 Origa는 현재 수준보다 조금 위에 있는 것을 고릅니다. 원칙은 **N+1**입니다. 새 문장은 대부분 이미 아는 단어에 새 단어 한두 개로 이루어져야 합니다. 인지 부하를 관리 가능하게 유지하면서 앞으로 나아가게 합니다.

선택은 알고 있는 어휘 인덱스가 이끕니다. 단어를 더 배울수록 Origa가 제공할 수 있는 문장 풀이 넓어집니다.

## 듣기 연습

레슨 중에 듣기 카드는 문장의 오디오를 재생하고 알아듣거나 받아 적게 합니다. 오디오는 원본 녹음이고 자연스러운 속도로 들립니다.

필요한 만큼 다시 들을 수 있습니다. 감속이나 음정 변경은 없습니다. 목표는 실제 말에 귀를 훈련하는 것입니다.

## 문장이 컬렉션에 들어오는 경로

문장은 직접 추가할 필요가 없습니다. 어휘가 늘어나면 복습 주기에 자동으로 들어옵니다. 속도는 설정한 일일 부하와 Origa가 수준에 맞춰줄 수 있는 문장 수에 달려 있습니다.

특정 출처가 끌린다면(예: 어떤 애니메이션의 어휘) 세트 페이지에서 세트로 가져올 수 있습니다. 가져온 문장은 다른 문장 카드와 같습니다. FSRS로 스케줄되고 듣기 카드 대상이 됩니다.

## 문장이 아닌 것

문장은 전체 대화 트랙이나 자막 달린 에피소드가 아닙니다. 더 긴 콘텐츠에서 뽑아낸 개별 문장입니다. Origa는 출처 영상이나 오디오를 전체로 포함하지 않습니다. 공부에 필요한 문장 단위 오디오만입니다.
