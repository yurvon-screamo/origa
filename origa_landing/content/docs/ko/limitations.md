# 알려진 제약

이 문서는 Origa의 현재 경계를 적습니다. 제약은 버그가 아닙니다. 앱이 오늘 하지 못하는 일을 적어, 당신의 학습 방식에 맞는지 판단할 수 있게 합니다.

## 오디오 전사는 WAV만 받습니다

음성 인식 기능은 `.wav` 파일을 받습니다. 다른 흔한 형식(MP3, M4A, OGG)은 현재 지원하지 않습니다. 올리기 전에 변환하세요. 전체 흐름은 [캡처](/ko/docs/capture)를 보세요.

## OCR은 어려운 입력에서 근사치입니다

광학 문자 인식은 인쇄물과 깨끗한 스크린샷에서는 잘 작동합니다. 크게 꾸민 글꼴, 대비가 낮거나 역광인 사진, 특이한 배치의 세로쓰기, 아주 작은 글자, 손글씨(지원 안 함)에서는 약합니다.

인식된 단어는 카드로 추가하기 전에 항상 검토하세요.

## 게스트 모드가 없습니다

Origa를 쓰려면 로그인해야 합니다. 진행 상황이 기기 간에 동기화되기 때문에 계정이 필요합니다. 오프라인 전용 모드나 익명 모드는 없습니다.

## 첫 실행에는 인터넷이 필요합니다

처음 로그인할 때 Origa는 사전과 콘텐츠를 내려받습니다. OCR이나 음성 인식을 처음 쓸 때 해당 모델이 내려받아집니다. 이 일회성 다운로드 뒤에는 앱이 오프라인으로 작동합니다. 전체 내역은 [시작하기](/ko/docs/getting-started)를 보세요.

## 동기화에는 인터넷이 필요합니다

진행 상황은 로컬에 저장되고 서버로 동기화됩니다. 오프라인이면 진행 상황이 대기열에 들어가고, 다시 연결되면 동기화됩니다. 인터넷 없이 다른 기기로 진행 상황을 보낼 수는 없습니다.

## 쓰기 연습은 애니메이션 기반입니다

한자 쓰기 기능은 올바른 획순을 따라 하게 하는 애니메이션으로 보여줍니다. 현재는 자유로운 필기를 인식하지 않습니다.

## 두 버튼 평가

카드마다의 평가는 이분법적입니다. 일반 복습에서는 **모름** 또는 **알음**, 익히기 훈련에서는 **기억함** 또는 **기억 안 함**입니다. 중간 선택지가 없습니다("어려움"이나 "쉬움" 같은). FSRS 스케줄러는 이 두 신호로 간격을 정합니다.

## 법적 문서는 영어와 러시아어만 있습니다

인터페이스와 학습 콘텐츠(어휘, 문장, 문법, 한자)는 한국어, 영어, 러시아어, 베트남어로 제공됩니다. 이 문서 페이지도 네 언어로 제공됩니다. 법적 문서(개인정보 처리방침, 이용약관)는 현재 영어와 러시아어로만 있습니다.
