# 어휘

어휘는 Origa의 핵심입니다. 이 문서는 단어가 어디서 오는지, 카드가 어떻게 만들어지는지, 직접 추가하는 방법을 다룹니다.

## 내장 사전

Origa에는 일본어와 사용자 언어를 잇는 이중 사전이 들어 있습니다. 단어를 추가하면 사전이 번역, 품사, 읽기를 공급합니다. 직접 바꾸고 싶은 게 아니라면 번역을 손으로 입력할 필요가 없습니다.

사전에 없는 단어는 일괄 만들기에서 건너뜁니다. 직접 번역을 붙여 수동으로 추가할 수는 있습니다.

## 오디오 발음

지원되는 단어에는 NHK 등 원어민 코퍼스에서 가져온 녹음 발음이 붙습니다. 오디오는 복습 중 카드에서, 단어 미리보기에서 재생됩니다.

모든 단어에 오디오가 있는 것은 아닙니다. 자주 쓰이는 어휘와 JLPT 수준 단어의 적용 범위가 가장 넓습니다.

## 카드 추가

어휘 카드를 만드는 방법은 네 가지입니다. 전체 흐름은 [시작하기](/ko/docs/getting-started)에 있고, 요약하면:

- **텍스트.** 일본어를 입력하거나 붙여 넣으면 Origa가 토큰화하고 번역을 찾습니다.
- **이미지.** 기기 내 OCR로 사진에서 일본어 텍스트를 추출합니다.
- **오디오.** `.wav` 녹음을 기기 내 음성 인식으로 전사합니다.
- **Anki 덱.** 기존 `.apkg` 파일을 가져옵니다. Origa가 단어 필드와 번역 필드를 자동으로 찾습니다.

한 번에 여러 단어를 추가하면 Origa가 미리보기 목록을 보여줍니다. 남길 것을 확인하고, 중복은 조용히 건너뜁니다.

## 미리 구성된 단어 세트

직접 목록을 만드는 대신, 흔한 학습 경로에 맞춘 세트를 가져올 수 있습니다:

- **JLPT 수준.** N5부터 N1까지 수준별로 정리된 공식 어휘.
- **교재.** Minna no Nihongo와 Irodori, 과별로 정리.
- **앱.** Duolingo(영어·러시아어 트랙), Migii JLPT 대비 세트.
- **콘텐츠.** 특정 애니메이션에서 뽑은 어휘, 스파이 패밀리로 시작합니다.

세트는 온보딩 중에, 또는 나중에 세트 페이지에서 가져올 수 있습니다. 각 세트는 컬렉션에 카드를 만들고, 언제든 복습하거나 제거할 수 있습니다.

## 카드 필드

어휘 카드에는 일본어 단어나 구, 읽기(한자에 붙는 후리가나), 사용자 언어 번역, 품사, JLPT 수준(알 경우), 오디오(있는 경우)가 담깁니다.

단어가 사전에 있으면 대부분 필드는 자동으로 채워집니다. 만든 뒤에는 어떤 필드든 고칠 수 있습니다.

## 컬렉션 관리

단어 화면은 컬렉션의 모든 카드를 나열합니다. JLPT 수준별, 출처별(가져온 세트 또는 직접 추가), 복습 상태별(새 것, 학습 중, 성숙)로 걸러 볼 수 있고, 일본어나 번역으로 검색할 수 있습니다.

카드를 지우려면 카드 상세를 열고 삭제하세요. 삭제는 영구적입니다. 휴지통은 없습니다.
