# 캡처: OCR과 음성 인식

Origa는 이미지에서 일본어를 읽고 오디오에서 받아 적을 수 있습니다. 두 기능 모두 기기에서 작동합니다. 처리 과정은 사진이나 녹음을 서버로 보내지 않습니다. 이 문서는 사용법과 한계를 다룹니다.

## 광학 문자 인식(OCR)

OCR은 이미지에서 일본어 텍스트를 추출합니다. 메뉴, 페이지, 간판, 스크린샷 등 시각적인 일본어 텍스트가 있을 때 쓰세요.

**사용법:**

1. 단어 화면을 열고 **이미지** 탭을 고르세요.
2. 이미지를 끌어다 놓거나 붙여 넣거나 기기에서 파일을 고르세요.
3. Origa가 OCR을 실행하고 인식된 텍스트를 보여줍니다.
4. 추출된 단어를 검토하고, 원하는 것을 골라 카드로 추가하세요.

**지원 형식:** PNG, JPEG, WebP. 최대 파일 크기 제한이 있습니다.

**모델이 다운로드되는 시점:** OCR 모델은 설치 파일에 포함되어 있지 않습니다. 기능을 처음 쓸 때 진행 표시와 함께 내려받습니다. 첫 다운로드 뒤에는 OCR이 오프라인으로 작동합니다.

**OCR이 잘 다루는 것:** 인쇄물, 깨끗한 스크린샷, 타이핑된 일본어.

**OCR이 약한 것:** 크게 꾸민 글꼴, 대비가 낮은 사진, 특이한 배치의 세로쓰기, 아주 작은 글자. 손글씨는 지원하지 않습니다.

## 음성 인식(STT)

STT는 오디오 파일에서 말하는 일본어를 받아 적습니다. 말하는 녹음이 있을 때 쓰세요. 팟캐스트 조각, 방송 대사, 음성 메모.

**사용법:**

1. 단어 화면을 열고 **오디오** 탭을 고르세요.
2. 오디오 파일을 올리세요.
3. Origa가 기기에서 전사하고 인식된 텍스트를 보여줍니다.
4. 검토하고 원하는 단어를 추가하세요.

**지원 형식:** WAV만 됩니다. 다른 흔한 형식(MP3, M4A, OGG)은 현재 받지 않습니다. 올리기 전에 변환하세요.

**모델이 다운로드되는 시점:** OCR과 마찬가지로 STT 모델은 포함되어 있지 않습니다. 첫 사용 때 내려받고, 이후 오프라인으로 작동합니다.

**STT가 잘 다루는 것:** 깨끗한 단일 화자 오디오, 느리거나 보통 속도.

**STT가 약한 것:** 겹치는 화자, 심한 배경 소음, 아주 빠른 말, 강한 억양. 인식은 근사치입니다. 단어를 추가하기 전에 결과를 검토하세요.

## 프라이버시

OCR과 STT는 모두 기기 안에서만 작동합니다. 넣은 이미지나 오디오는 로컬에서 처리되고 업로드되지 않습니다. 네트워크 트래픽은 Origa CDN에서 모델을 처음 내려받는 것뿐입니다.

## 캡처를 쓸 때

캡처는 어휘를 추가하는 주된 방법이 아닙니다. 이미 아는 단어는 직접 입력하는 게 더 빠릅니다. 캡처가 빛나는 때:

- 종이 자료(책, 간판)를 읽으며 타이핑 없이 모르는 단어를 담고 싶을 때.
- 만화 뷰어나 자막 스크린샷을 카드로 바꾸고 싶을 때.
- 오디오 콘텐츠에서 들은 단어를 (대충 들은 대로) 타이핑하지 않고 찾고 싶을 때.
