# Счётные суффиксы японского

Японский считает предметы суффиксами-счётчиками: длинные предметы — 本, плоские — 枚, небольшие животные — 匹, люди — 人. Origa рассматривает каждый суффикс как одну карточку и тренирует внутри неё два вида знания.

## Один суффикс — одна карточка

Карточка суффикса несёт сам знак — что им считают — и связки с числами: чтения от одного до десяти, вопросительную форму 何 и несколько застывших форм за десяткой (дни месяца вроде 二十日, читается はつか). Знакомство происходит как с любой новой картой: слайд показа выводит суффикс крупно, его значение на вашем языке и полную таблицу чтений с подсветкой нерегулярных.

## Значение и связки стареют отдельно

Значение суффикса («длинные предметы: карандаши, бутылки, деревья») и его связки с числами (三本 → さんぼん) живут по разным расписаниям повторений. В обычном повторении вы либо оцениваете значение кнопками «Знаю / Не знаю», либо урок выдаёт пачку связок: серию коротких вопросов, где видно число с суффиксом и нужно выбрать верное чтение. Каждая связка запоминает свои ответы, поэтому нерегулярные чтения вроде いっぽん, さんぼん, ろっぽん возвращаются чаще регулярных — а те по мере закрепления выпадают из ротации.

После каждого ответа в пачке показывается таблица чтений всего суффикса, строка только что отвеченной связки подсвечена. Это та же таблица, что вы видели на первом знакомстве, — теперь как обратная связь.

## Откуда берутся счётчики

Счётчики приходят с уровнем: онбординг-импорт добавляет суффиксы вашего уровня JLPT и ниже, а отдельная страница счётчиков показывает весь список с детальной карточкой каждого — можно посмотреть, добавить и повторить самостоятельно. Добавление слова с числительным сочетанием (一本) из текста тоже предлагает счётчик отдельным кандидатом. Если суффикс уже знаком — отметьте «уже знаю»: и значение, и дрилл связок пропускают тренировку. Для аккаунтов, созданных до появления счётчиков, разовая миграция при первом запуске после обновления находит суффиксы, которые ваш словарь уже встречал.

Датасет ведётся как файл данных и покрывает суффиксы из распространённых учебников, сгруппированные по уровням JLPT по редакторскому консенсусу — официального списка счётчиков для JLPT не существует. Глоссы поддерживаются на английском, русском, корейском и вьетнамском. Источники — на странице [источников данных](/ru/docs/data-sources).
