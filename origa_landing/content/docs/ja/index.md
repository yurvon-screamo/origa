# Origaドキュメント

Origaの仕組みと使い方のガイドです。

## はじめに

初めての方はここから始めてください。インストール、ログイン、オンボーディング、最初のレッスン、自分のカードの追加方法を説明します。

→ [はじめに](/ja/docs/getting-started)

## 機能別

- **[レッスン](/ja/docs/lesson):** レッスンの内容、新規カードのacquaintanceステージ、カードの種類、評価、間隔反復による復習スケジューリング。
- **[助数詞](/ja/docs/counters):** 助数詞（本、枚、匹）の学習方法: 意味と数字の結びつき、助数詞ごとのカード。
- **[Origaが何を見せるかを決める仕組み](/ja/docs/fsrs):** 忘却曲線、FSRS、ペースと1日の上限: カードが尽きる理由と、それが正常である理由。
- **[語彙](/ja/docs/vocabulary):** 内蔵辞書、音声発音、カード追加の4つの方法、既製語彙セット。
- **[漢字](/ja/docs/kanji):** 学習が進むと隠れる自動ふりがな、筆順アニメーションの書き取り練習、JLPT対応の漢字。
- **[文法](/ja/docs/grammar):** すでに知っている語彙で例文が作られる、JLPT別のリファレンス。
- **[フレーズと聴解](/ja/docs/phrases):** ネイティブ音声付きフレーズ、レベルに合わせた自動選択。
- **[キャプチャ](/ja/docs/capture):** 端末上のOCRと音声認識: 使い方、モデルのダウンロードタイミング、既知の限界。

## リファレンス

- **[限界](/ja/docs/limitations):** Origaの現在の境界を率直に説明します。
