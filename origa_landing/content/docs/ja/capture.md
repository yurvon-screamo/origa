# キャプチャ: OCRと音声認識

Origaは画像から日本語を読み取り、音声から文字起こしできます。どちらの機能も端末上で動作し、写真や録音がサーバーに送られることはありません。このページでは使い方と限界を説明します。

## 光学文字認識（OCR）

OCRは画像から日本語テキストを抽出します。メニュー、ページ、看板、スクリーンショットなど、視覚的な日本語テキストがあるときに使います。

**使い方:**

1. 単語画面を開き、**画像**タブを選びます。
2. 画像をドロップ・貼り付け、または端末からファイルを選びます。
3. OrigaがOCRを実行し、認識したテキストを表示します。
4. 抽出された単語を確認し、必要なものを選んでカードに追加します。

**対応形式:** PNG、JPEG、WebP。ファイルサイズの上限があります。

**モデルのダウンロード:** OCRモデルはインストーラーに同梱されていません。この機能を初めて使うときに、進捗表示付きでダウンロードされます。初回ダウンロード後、OCRはオフラインで動作します。

**OCRが得意なもの:** 印刷テキスト、鮮明なスクリーンショット、タイピングされた日本語。

**OCRが苦手なもの:** 強く装飾されたフォント、コントラストの低い写真、特殊なレイアウトの縦書き、極端に小さい文字。手書きテキストには対応していません。

## 音声認識（STT）

STTは音声ファイルから話される日本語を文字起こしします。ポッドキャストの一部、番組のセリフ、ボイスメモなど、発話の録音があるときに使います。

**使い方:**

1. 単語画面を開き、**音声**タブを選びます。
2. 音声ファイルをアップロードします。
3. Origaが端末上で文字起こしし、認識したテキストを表示します。
4. 確認して、必要な単語を追加します。

**対応形式:** WAVのみ。他の一般的な形式（MP3、M4A、OGG）は現在受け付けません。アップロード前に変換してください。

**モデルのダウンロード:** OCRと同様、STTモデルは同梱されていません。初回使用時にダウンロードされ、以降はオフラインで動作します。

**STTが得意なもの:** 障害物のない单一話者の音声、普通の話速まで。

**STTが苦手なもの:** 話者の重なり、大きな背景ノイズ、非常に速い話速、強い訛り。認識は近似です — 追加する前に出力を確認してください。

## プライバシー

OCRもSTTも完全に端末上で動作します。与えた画像や音声はローカルで処理され、アップロードされることはありません。ネットワーク通信は、OrigaのCDNからの一時的なモデルダウンロードだけです。

## キャプチャを使う場面

キャプチャは語彙追加の主な方法ではありません。すでに知っている単語なら、タイピングの方が速いです。キャプチャが輝くのは:

- 紙の資料（本、看板）を読んでいて、タイピングせずに未知の単語を拾いたいとき
- 漫画リーダーや字幕のスクリーンショットをカードに変えたいとき
- 音声コンテンツで聞いた単語を、（おおよそ）聞こえた通りにタイプせずに調べたいとき
