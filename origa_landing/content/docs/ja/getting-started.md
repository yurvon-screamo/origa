# はじめに

Origaは端末上で動く日本語学習アプリです。このガイドでは最初のセッション（インストール、ログイン、レベル設定、単語のインポート、最初の復習）を順に説明します。

セットアップの大部分は一度だけです。初回ロード後、Origaはオフラインで動作します。

## 1. インストール

OrigaはiOS・iPadOS（App Store）、macOS（Mac App Store）、Windows、Linux、Androidで利用できます。ブラウザで動くWeb版もあります。

[ダウンロード →](/ja/download)

プラットフォームに合ったパッケージを選んでください。iPhone・iPad・MacはApp Storeからインストールします（インストーラーは不要）。WindowsとLinuxではインストーラーがアプリフォルダにOrigaを配置します。Androidでは、システムに求められたらインストールを許可してください。

## 2. ログイン

最初の画面でログインします。GoogleアカウントまたはYandexアカウント、メールアドレスとパスワードでログインできます。

ゲストモードはありません。学習の進捗をデバイス間で同期し、続きから再開するために、アカウントが必要です。初回ログイン時にプロフィールが自動作成されます。

インターフェースの言語はログイン画面または最初のオンボーディング手順で切り替えられます。

## 3. オンボーディング

初回ログイン後、Origaは短いセットアップを開きます。完了してもスキップしても構いませんが、スキップすると最初のレッスンが空になります — Origaはまだカードを1枚も持っていないからです。

セットアップは4つを決めます:

- **言語。** インターフェースと翻訳の言語を選びます: 英語、ロシア語、韓国語、ベトナム語。
- **ペース。** 1日に覚える新しいカードの枚数を、最小から最大まで選びます。後からプロフィールで変更できます。
- **レベル。** 現在のJLPTレベル（N5〜N1、または「不明」）を伝えます。それより下の内容をすでに知っていれば、Origaは既知としてマークし、習得済みのものを復習させません。
- **アプリと教材。** 他のツール（Anki、Migii、Duolingo、みんなの日本語、いろどり）で学習したことがあれば、選んで進度を伝えてください。対応する語彙をインポートするので、ゼロから始めることになりません。

セットアップの最後に、Origaは辞書・漢字・文法・フレーズのデータを読み込みます。この手順だけインターネット接続が必要です。終われば、以降はオフラインで学習できます。

## 4. 最初のレッスン

セットアップが終わると、ホーム画面にJLPT進捗と今日の復習分が表示されます。そこからレッスンを開始します。

レッスンはカードの連続です。問題を見て、答えを表示して、覚えていたかを評価します。その評価に基づき、間隔反復スケジューラが次に表示する時期を決めます。

今日の新規カードがあれば、レッスンは「 acquaintance（知る）」ステージから始まります: 新しいグループ（ふりがなと翻訳付きの単語、漢字、文法）を見て、短い練習ラウンドを行います。ステージは「復習へ」の画面で終わり、その後、通常部分のレッスンが始まります。詳細は[レッスンの仕組み](/ja/docs/lesson)を参照してください。

通常部分は2ボタン評価です — 「わからない」か「わかった」（acquaintance練習では「覚えた」/「覚えていない」）。カードはいくつかの形で出ます: 認識（日本語→あなたの言語）、想起（あなたの言語→日本語）、聴解、書き取り、漢字の読み、文法。Origaは学習履歴と復習期限に基づいてその組み合わせを選びます。

レッスンが終わると、進捗がサーバーに同期されます。そこから次のレッスンを始めることも、ダッシュボードに戻ることもできます。

## 5. 自分のカードを追加する

自分に関係あることを学ぶ最も直接的な方法は、自分の語彙を追加することです。単語画面を開き、4つの作成方法から選びます:

- **テキスト。** 日本語の単語や文を入力・貼り付けします。Origaが形態素解析し、翻訳を引き、作れるカードのプレビューを表示します。残すものを選んでください。
- **画像。** 写真をドロップ・貼り付け、またはファイルを選びます。Origaは端末上でOCRを実行し、日本語テキストを抽出します。確認して追加します。認識モデルはこの機能を初めて使うときにダウンロードされます。
- **音声。** `.wav`録音をアップロードします。Origaは音声認識モデルで端末上に文字起こしし、認識した単語を追加します。OCRと同様、モデルは初回使用時にダウンロードされます。
- **Ankiデッキ。** 既存の`.apkg`ファイルをインポートします。Origaが単語と翻訳のフィールドを自動検出し、カードを取り込みます。

4つすべてで、可能な範囲で発音（ふりがな）、品詞、JLPTレベルを自動入力します。重複する単語はスキップされます。

## 6. オフラインでできること

初回セットアップ後、Origaの大部分はインターネットなしで動作します:

- テキスト・画像・音声からのカード作成
- レッスンと復習
- 間隔反復スケジューリング
- Ankiデッキの追加
- 音声読み上げ（TTS）発音

インターネットが必要なのは:

- 初回ログイン
- 初回起動時の辞書とコンテンツの読み込み
- 初回使用時のOCR・音声認識モデルのダウンロード
- デバイス間の進捗同期
- アプリのアップデート確認
- カタログからの既製語彙セットのインポート

フライトや長い通勤など、しばらくオフラインになることがわかっている場合は、**プロフィール → オフラインバンドル**を開いて必要なものを事前にダウンロードしてください。その後は、アカウント同期だけがインターネットを必要とします。
