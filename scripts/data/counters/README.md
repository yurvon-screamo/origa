# Counters dataset (ручной источник)

Ручной источник данных счётных суффиксов (counter words, 助数詞) для типа карточек
«Счётный суффикс» — issue #415, Slice 4. Формат и инварианты — `counters.manual.json`
(`meta.description`).

## Почему здесь, а не в cdn/

`cdn/` — gitignored генерируемый артефакт: положенные туда «ручные» данные теряются
при пересборке машины (так были утеряны артефакты первой редакции плана #415).
Поэтому ручной датасет живёт в git — прецедент `!scripts/data/` (grammar N1
authoring batches). Сборщик Slice 4 разворачивает полный
`cdn/counters/counters.json` из этого файла.

## Схема (компактная)

Ручной файл хранит только то, что не выводится машиной:

- `number_readings` — он-чтения числительных 1–10 и 何 (0);
- на счётчик: `suffix`, `level`, `repr_reading` (канон чтения суффикса),
  `glosses` (**обязательны все 4 локали: RU/EN/KO/VI** — паритет с `grammar_v3.json`
  и `dictionary/chunk_*.json` на проде; staged-этап ADR-047 завершён, KO/VI-контент
  уже раздаётся нативно),
  `irregular` (ячейки 1–10/0, где чтение ≠ регулярная конкатенация:
  мутация 音便, кун-числительное, уникальное исключение),
  `beyond_ten` (лексикализованные исключения >10: 日 14/20/24, 歳 20),
  `verified` (пометки сверки).

Полная ячейка = `irregular[n]` если задана, иначе `number_readings[n] + repr_reading`.
`repr_reading: null` означает чисто кун-серийный счётчик (つ) — `irregular` обязан
покрывать всю серию 1–10 и 0.

## Provenance

- **Оракул**: [naclsn/josuushi](https://github.com/naclsn/josuushi) (`data/`,
  39 счётчиков) — использован только для сверки чтений. Репозиторий без явной
  лицензии: его файлы не копируются, датасет написан с нуля (чтения —
  лингвистические факты). Пометки `josuushi` / `josuushi:alt X` в `verified`.
  Автосверка покрывает только ячейки, представленные у оракула; остальные
  (6/8/10/何-мутации вне оракула) выведены из правил 音便 и чеклистов.
- **Чеклисты**: Tofugu «350 Japanese Counters», Wikipedia «Japanese counter word»
  (таблицы 音便). Пометки `tofugu`.
- **Правила 音便** (h→p/b, s→j/z, っ-стягивания): пометки `rule:` — ячейки, которые
  оракул пропускает, но которые следуют из общего правила (本 8 はっぽん, 歳 20 はたち).
- **Выбор канона** среди словарных вариантов: пометки `canon:N X (alt Y)`.

## JLPT-группировка

Редакторская — официального распределения счётных суффиксов по уровням JLPT не
существует. Группировка по консенсусу учебников (Minna no Nihongo / Genki /
JLPT-подготовка): **N5:19 / N4:14 / N3:18 / N2:16 / N1:9 = 76**.

Упрощения v1:

- 羽 — только わ-серия (разговорные ば-варианты じゅっぱ не включены);
- 日 1 = ついたち (календарная серия; чтение いちにち «длительность» — в verified-пометке);
- 棟 — кун-серия 1–2 (ひとむね/ふたむね), дальше он-серия ぼう;
- 皿/箱/切れ — кун-тройка 1–3, дальше он-конкатенация.

## Проверка

Сборка и валидация — Slice 4 (ишью #415). Инварианты: JSON валиден; 76 записей;
уникальные `suffix`; глоссы непустые во всех 4 локалях (RU/EN/KO/VI); `repr_reading: null` → полная серия в
`irregular`; ключи `irregular` ∈ 0–10, `beyond_ten` > 10; все чтения — кана;
контраст-точки 音便 (いっぽん/さんぼん/はっぽん/さんばい/ひとり/ふたり/ろっぴき/さんぷん/
ついたち/はつか/よじょう — 歳 20 はたち в N5-датасете) присутствуют.
